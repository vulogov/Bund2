review — every program run for this file agreed across tiers, every figure
the newest notes quote reproduced, and no citation into `reference/` is
wrong. The document is not. Its status block contradicts itself in the first
ninety lines, its preservation table — the section this review is asked to

answers were filed where the review pointed and nowhere else. B6's notes went

**B5 — Criterion 17's new check fails silently, and the failure recompiles
the body on every entry. Read; two short functions.** The amendment of
2026-10-11 says `guards_hold` runs on every compilation in shipped builds
and "a body that fails does not compile". It does: `compile_word` returns
`Err` (`lower.rs:3341-3356`). `JitTier::enter` then does
`if let Ok(code) = compiler.compile_word(…) { insert }` with no `else`
(`crates/bund2-runtime/src/tier.rs:440-443`), under a comment that a failure

could act on". A `guards_hold` refusal is not a user condition; it is the
lowering failing its own invariant, which is D37's `Error::internal` case.
And nothing demotes the body or caches a refusal, so the counter stays past
the threshold and `observe` answers `Decision::Compile` on the next entry
(`crates/bund2-jit/src/cache.rs:310-320`): a full Cranelift lowering per
entry, forever, with `--stats` reading 0 bodies. The same arm swallows every
other `compile_word` error. The RFC's answer to B8 does not say what a
failure does; this is what it does.

## What the RFC assumes and does not state

1. A failed compilation is a user-invisible event (B5). It is a D37 event.
2. `plan_body`'s answer for a body is a function of the body alone (S2). It
   is a function of the registry at planning time.
3. The clock and the count measure the same criterion (B4).
4. A compiled entry counted anywhere in a run is the entry whose outcome a
   differential compares (S9).
5. `compiled_bodies() > 0` or `Ok(_)` from `Compiler::run` means a compiled
   word ran (criteria 12, 14, 22 bullet 6).
6. `LastCall::Ordinary`-only compilation still satisfies the "tail position"
   rows of criteria 26, 29 and 30; the runtime tests treat tail as
   body-final position, the `lower.rs` tests use `LastCall::Tail` on
   synthetic natives.
7. `--stats` has exactly two lines; `conform` and two CLI tests strip them
   by text and would break on a third (D147 says so; the RFC does not).
8. Compiled bodies nest at most to the Tier 1 floor and the floor is read in
   the C-convention trampoline once per entry, not per function (`lower.rs:3385-3393`).
9. `Fragment::admits_with` is the single guard predicate for both `frag::run`
   and `jit_admits`.
10. No fixed-effect native takes a stack name below the top two (assumption
    23) — asserted by no scan.
11. `Declined`'s slot choice (`key >> 7`) spreads under allocators other than
    macOS's; D146 lists Linux as not covered.
12. An `Interp` runs on the thread that built it (unchanged since 2026-10-10).
