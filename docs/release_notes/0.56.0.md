# Bund2 0.56.0

*In development.*

## SMYSL 1.15.0, from crates.io

The `smysl` features now take SMYSL's published crates, at exactly
1.15.0, in place of a git revision of 1.14.0 (D244 R2, RFC-0014 U6).
Nothing changes for a build without them.

- **Anthropic works.** SMYSL 1.15.0's Anthropic mapper moved to the
  current API and models and no longer sends `temperature`, which every
  current model refused (RFC-0014 U19). A `bund2` built with
  `smysl-anthropic` runs `smysl.ingest`, `smysl.ingest.text` and
  `smysl.answer` against `claude-opus-5-5`; checked live through
  `bund_examples/smysl_model`.
- What else 1.15.0 brings to a model call, from its changelog: a chunk is
  never wider than the provider's `max_output`, an Anthropic system prompt
  is cached across a run's calls, and a policy decline is an error naming
  its category rather than an empty answer.
